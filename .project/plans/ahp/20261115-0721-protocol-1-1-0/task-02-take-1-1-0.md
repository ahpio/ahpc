## Objective

`package.json` and both lockfiles take 1.1.0, `VERSIONS` offers it first, and the strict schema is regenerated from it.
Every document that names the protocol version says 1.1.0.

## Files

- `UPDATE: package.json:61` - `^1.0.0` becomes `^1.1.0`.
- `UPDATE: package-lock.json` - the 1.1.0 tarball and its integrity hash, written by `npm i`.
- `UPDATE: deno.lock` - the 1.1.0 entry, written by `deno`.
- `UPDATE: src/ahp/live.ts:41` - the module comment says it is written against 1.1.0.
- `UPDATE: src/ahp/live.ts:209-237` - `VERSIONS` gains `1.1.0` first; the comment names 1.1.0 as the newest published and what it adds that is not drawn.
- `UPDATE: tools/ahp.strict.schema.json` - regenerated by `npm run schema`.
- `UPDATE: test/reconnect.test.ts:1171-1177` - the test name and the expected list start with `1.1.0`.
- `UPDATE: README.md:8` - the badge says 1.1.0.
- `UPDATE: docs/CONFORMANCE.md:8-11` - the package checked against is 1.1.0, offered first, with 1.0.0 behind it.
- `UPDATE: .project/plans/ahp/00-ahp.md` - the package line names `npm://@microsoft/agent-host-protocol@^1.1.0`.

## Steps

1. Run `npm i @microsoft/agent-host-protocol@^1.1.0`.
2. Set `VERSIONS` to `['1.1.0', '1.0.0', '0.10.0', '0.9.0', '0.8.0', '0.7.0']`.
3. Rewrite the `VERSIONS` comment for 1.1.0, and keep its paragraph on `0.10.0`.
4. Change the module comment at `src/ahp/live.ts:41` to 1.1.0.
5. Run `npm run schema`.
6. Update the offered-order test at `test/reconnect.test.ts:1171`.
7. Run `deno install` to bring `deno.lock` to 1.1.0, and check that `git diff deno.lock` touches only the protocol package.
8. Update `README.md`, `docs/CONFORMANCE.md` and `00-ahp.md`, keeping the hard wrap of `docs/CONFORMANCE.md`.
9. Run `npm run typecheck`, `npm test` and `npm run build`.

## Validation

- `npm run typecheck` gives no error, and `npm test` passes, with the conformance test on the new schema.
- `test/reconnect.test.ts` asserts the offer `['1.1.0', '1.0.0', '0.10.0', '0.9.0', '0.8.0', '0.7.0']`.
- `rg -n 'agent-host-protocol@1\.0\.0|agent-host-protocol-1\.0\.0|AHP-1\.0\.0' package-lock.json deno.lock README.md` finds nothing.
- By hand: `ahpc --wire` against a VS Code host on 1.1.0 records `protocolVersion: "1.1.0"` in the `initialize` result.
